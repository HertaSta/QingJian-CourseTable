数据

导入

从教务系统导入（安卓版，推荐）：在应用内打开学校教务系统，你自己登录、自己打开课表页，再点「执行导入」把课表读回来，不必先导出文件。多数学校需要先连校园网。
导入 Excel（备选）：先在教务系统导出 .xlsx / .xls，再回到这里选文件；导入时可选择覆盖、新建或合并到当前课程表。

导出

.ics 文件可导入手机自带日历、谷歌日历或 Outlook，每节课按周次生成日程。备份文件包含全部课程表与设置，更换手机或重装后可用它恢复。

恢复与清空

数据仅保存在本机。除本地存储外，安卓版还会在应用私有目录保存一份，清理后台不会丢失。更换手机时请使用「导出备份」迁移。

意见反馈

给开发者发邮件

遇到问题、想要的功能，或者只是想吐槽，都可以直接发邮件。描述里带上手机型号和系统版本会更容易定位。
点上面这个按钮会调起手机上的邮件应用，主题和正文已按当前版本填好，你只要补上具体描述就行。手机上没装邮件应用的话，用旁边的「复制」把地址抄走即可。

也可以在开源仓库提 Issue

本应用在 GitHub 上开源，功能建议和问题都能在仓库的 Issue 里讨论，也欢迎直接改代码提 Pull Request。

反馈时会带出哪些信息

只有点「用邮件应用发送」时，才会自动在邮件正文末尾附上当前版本号（v）与来源（安卓版 / 网页版）。不会自动附带你的课程表、个人资料或任何本机数据，写什么、发不发完全由你决定。
