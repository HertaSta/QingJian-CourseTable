## 签名

自 v0.1.0 起，所有正式版与测试版均使用同一把密钥签名（`android-app/android/qingjian-release.jks`）。

- 证书主题：`CN=Reiro.`
- 证书 SHA-256：`a743d74ef60fd3ce1ac6d4793dddfe40f113c5e2d9caceca5fdb3f1f1bea8bee`
- 同钥意味着**新版可以直接覆盖安装旧版，无需先卸载**；测试版也因此可以直接覆盖上一个测试版
  （`v0.1.5-test` 是 versionCode 6，`v0.1-test` 是 7）。
- ⚠️ 密钥文件务必长期保管；一旦更换，所有老用户都将无法覆盖安装。

### 非签名包（已删除）

早期曾产出过一个未签名的调试包（`清笺课程表-test-教务系统导入.apk`，13,800,626 字节），
因 debug 未签名、且 versionCode 与 v0.1.4 相同，部分机型装不上，已被 v0.1.5-test 取代并删除。

## 安装说明

- 最低支持 Android 10（API 29），目标 API 34。
- 正式版声明权限：`INTERNET`、`REQUEST_INSTALL_PACKAGES`、`READ_CALENDAR`、`WRITE_CALENDAR`。
  后两项只在「添加日程 → 同步到系统日历」时才向系统申请。
- 安装时系统可能提示「未知来源应用」，需手动允许。
