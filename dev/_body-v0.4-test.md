## 清笺课程表 测试版 v0.4-test

**本仓库只放测试版**，正式版请到公开仓库 [QingJian-CourseTable](https://github.com/HertaSta/QingJian-CourseTable) 下载。

### 本版改动

**一、教务导入合并为单一入口**

原来写死武汉铁路职业技术学院的「从教务系统直接导入」已并入统一面板，界面上不再有两个入口互相打架。

**二、内置 249 所学校的适配脚本，选学校即可，不用自己填网址**

脚本与教务网址取自开源项目「拾光课程表」的脚本仓库（MIT 许可，Copyright (c) 2025 星河欲转），
随安装包一起打包，离线可用、不额外联网。列表支持搜索，按首字母分组。

| 选项 | 走哪条路 | 怎么操作 |
|---|---|---|
| **武汉铁路职业技术学院**（本校） | 早已验证的 ZwBridge 通道 | **登录后自动读取课表**，不用自己导出；没读到可点窗口右上角「读取课表」 |
| **清单里的学校**（249 所 / 270 个适配器） | 该校专用适配脚本，网址已内置 | 选中后直接打开教务系统，登录后打开课表页点「执行导入」 |
| **其他学校** | 四类通用脚本（正方 / 超星 / 青果 / URP） | 选系统类型 + 填贵校教务网址 |

- 本校仍走 ZwBridge，武铁上不会有任何回退；想对比通用脚本可选「其他学校 → 正方」
- 设置 → 数据 → 导入 里的入口也打开同一个面板，不再绕过学校选择
- 手动填过的网址会记住，下次不用重填
- 不保存任何登录凭据，每次需手动登录

### 同时包含（自 v0.1-test 起）

- 日程页「添加日程」，可同步到手机自带日历（提前提醒、修改先删后建）
- 日历读写权限只在添加日程并打开「同步到系统日历」时才申请

### 安装说明

- 包名 `com.reiro.qingjian.test`，与正式版共存，数据互不干扰
- 最低支持 Android 10（API 29），目标 API 34
- 同一把签名密钥，可直接覆盖安装上一个测试版，无需卸载
