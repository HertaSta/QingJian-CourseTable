## 清笺课程表 测试版 v0.3-test

**本仓库只放测试版**，正式版请到公开仓库 [QingJian-CourseTable](https://github.com/HertaSta/QingJian-CourseTable) 下载。

### 本版新增：通用教务导入（多校适配）

导入页新增「通用教务导入（多校适配）」入口：应用内全屏 WebView 打开目标学校的教务系统，手动登录后自动抓取课表，数据回到原有「确认导入」面板，覆盖 / 新建 / 合并三个选项与去重逻辑原样复用。

- 自写原生插件 `UniImportPlugin`：全屏 Dialog + WebView，完整复刻拾光课程表的桥协议
- 内置 4 套通用适配脚本：正方（覆盖武汉铁院）、超星、青果、URP
- 脚本带回开学日期时直接采用，不再追问「本周是第几周」
- 不保存任何登录凭据，每次需手动登录

### 同时包含（自 v0.1-test 起）

- 日程页「添加日程」，可同步到手机自带日历（提前提醒、修改先删后建）
- 日历读写权限只在添加日程并打开「同步到系统日历」时才申请

### 安装说明

- 包名 `com.reiro.qingjian.test`，与正式版共存，数据互不干扰
- 最低支持 Android 10（API 29），目标 API 34
- 同一把签名密钥，可直接覆盖安装上一个测试版，无需卸载
