## 清笺课程表 v0.1.7

> 2026-10-29 更新：本版追加了「意见反馈」，安装包已重新打包并覆盖本 Release 的附件。
> 版号仍是 `v0.1.7`（`versionCode 8`），已安装过 v0.1.7 的朋友请手动下载覆盖安装。

### 本版改动

**一、新增「意见反馈」**

设置 → 关于 → **意见反馈**，可以直接联系开发者：

- 展示开发者邮箱 **`nangongshuo33@gmail.com`**，旁边「复制」一键抄走
- 点「用邮件应用发送」会调起手机上的邮件应用，主题与正文已按当前版本填好，你只要补上具体描述
- 邮件正文末尾只自动附上**版本号与来源（安卓版 / 网页版）**，**不会附带课程表、个人资料或任何本机数据**
- 另附「打开项目仓库」，可在 GitHub 上提 Issue 或 Pull Request
- 隐私政策的「联系我们」与联网说明同步更新

**二、「上课提醒」改为「一键导入日历」**

旧的上课提醒靠网页定时轮询，应用一退出就不响，效果有限。本版把入口挪到主页「更多」菜单，直接写进手机自带的日历，由系统负责到点提醒，应用完全退出也照响。

- 主页 →「更多」→ **「一键导入日历」**
- 弹窗里选择**是否提醒**、**提前多久**（提前 5 / 10 / 15 / 30 分钟，或不提醒）
- 确认后把当前课表**逐周展开**，把每一节写进系统日历，每节都带上你选的提醒时间
- **改了课表再点一次即可重建**：会先清掉上次导入的课，不会在日历里堆重复
- 也可以**取消导入**，一键清空日历里的课
- 设置页原有的「上课提醒」模块已移除，避免两套开关各管一半

**三、修掉两处此前测试版反馈的问题**

- 教务系统窗口里点取消后，原来会直接关闭整个面板，无处可回；现在回到学校列表
- 搜索框用中文输入法打完字，结果不刷新、要再删一个字才更新；现已即时刷新

### 安装说明

- 包名 `com.reiro.qingjian`，**直接覆盖安装**即可，无需卸载，课表数据不会丢
- 版本号 `versionCode 8`，系统设置里显示 `0.1.7`
- 首次点「一键导入日历」时会申请日历读写权限，允许后才能写入
- ⚠️ 本次为同版号重打，应用内「检查更新」不会提示，请手动下载本页附件覆盖安装

### 其他

- 网页版不受影响，仍是「导出为日历（.ics）」后在手机日历里导入文件

> 桌面小组件功能尚未包含在本版中，仍在开发与验证，完成后再单独发布。
