## 清笺课程表 测试版 v0.0.6

**本仓库只放测试版**，正式版请到公开仓库 [QingJian-CourseTable](https://github.com/HertaSta/QingJian-CourseTable) 下载。

### 本版改动

**一、学校列表按教务系统类别分成三个页签**

进入「从教务系统导入」后，学校列表上方多了一排页签：**本科 / 高职**、**研究生**、**通用系统**，
按学校所属的教务系统类别分栏显示，不用在两百多行里翻。每所学校下方仍标注它的类别。
搜索是跨类别检索的 —— 当前停在哪个页签，都能搜到全校清单里的学校。

**二、导入教程分成「从教务系统导入」与「导入 Excel 文件」两块**

原来的教程只有导出 Excel 一条路。现在按做法分成两块，各自独立的步骤：

| 分栏 | 步骤 | 适合 |
|---|---|---|
| 从教务系统导入 | 5 步（连校园网 → 选学校 → 登录 → 读取课表 → 核对导入） | 安卓版 |
| 导入 Excel 文件 | 6 步（连校园网 → 进教务系统 → 登录 → 打开课表页 → 导出 Excel → 回应用导入） | 网页版 / 想留一份文件 |

**三、点本校直接进教务系统，去掉跳转前的提醒弹窗**

以前点「武汉铁路职业技术学院」会先弹一个说明窗口，要点「我知道了」才进去。现在**点了就直接打开**教务系统，
少一步。账号密码依旧只在教务系统的页面里输入，应用不读取、不保存、不上传。

**四、修：打开教务系统后按返回，不再被直接丢回课表页**

以前在教务系统窗口里按返回键（或点「关闭」），会连学校列表一起关掉，直接被丢回课表页，想换一所学校得从头点进来。
现在取消后会**回到刚才的学校列表**，可以直接改选，选中的学校也还在。

**五、学校列表：每所学校下方标注教务系统类别**

类别取自开源项目「拾光课程表」适配器自带的 `category` 字段（100% 覆盖），不是靠名称猜的：

| 标签 | 含义 | 数量 |
|---|---|---|
| **本科 / 高职** | 面向本科与专科 | 252 |
| **研究生** | 面向研究生 | 14 |
| **通用系统** | 通用教务工具 | 4 |

**六、武汉铁路职业技术学院并入普通列表，全面去特殊化**

- 本校不再是列表顶部单独一行，按首字母并入正常位置（落在 W 组），**不置顶、不默认预选、不额外标注**
- 点它仍走已验证的直连通道：登录后自动读取课表，不需要手动导出
- 关于页 / 隐私政策 / 使用说明 / README 里「仅适配本校」「以本校格式为完整验证」的说法全部去掉
- 联网说明补上「从教务系统导入也会联网」，并写明凭据不读取、不保存、不上传

**七、修：搜索框里打完字不出结果，要删一个字才刷新**

安卓 WebView 里中文输入法的候选词是在 `compositionend` 那一刻才写进输入框的，且常常不补发 `input` 事件；
用回车选词时那个 Enter 也被输入法自己吃掉。原先只绑了 `input`，于是打完字列表不动。现在 `input` / `compositionend` /
`change` / 回车 全部接上，统一读输入框现值；`isComposing` 时把回车让给输入法。

**八、默认头像不再显示昵称首字母**

没设头像时，头像位置原先会显示昵称（或学校名）的首字母。现在**留空白**，只保留渐变底色，等你自己从相册选一张。

### 同时包含（自 v0.0.5 起）

- 导入面板学校列表为限高滚动区，**点一下学校名就直接打开该校教务系统**
- 内置 **249 所学校 / 270 个适配器**，网址已内置；列表外的学校选「其他学校」，按系统类型 + 网址走通用脚本
- 不保存任何登录凭据，每次需手动登录
